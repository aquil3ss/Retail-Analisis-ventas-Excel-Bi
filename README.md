# Retail – Análisis de Clientes y Desempeño de Ventas

## 📌 Descripción del proyecto
Proyecto académico grupal desarrollado en el curso **Data Analytics – ESPOL**, enfocado en el análisis del comportamiento de clientes y el desempeño de ventas en el sector retail.  
Se aplicaron procesos de **limpieza, transformación y análisis de datos en Excel**, con el objetivo de generar insights que respalden la toma de decisiones comerciales.

## 🎯 Objetivo
Identificar patrones de consumo, evaluar ingresos, analizar el **ROI de campañas** y medir el desempeño comercial para optimizar la toma de decisiones estratégicas.

## 🧠 Actividades realizadas
- Limpieza y depuración de datos utilizando **Excel avanzado**  
- Definición y cálculo de métricas clave (ingresos y ROI)  
- Creación de **tablas dinámicas** para el análisis de información  
- Desarrollo de **gráficos y visualizaciones** a partir de tablas dinámicas  
- Elaboración de **reportes ejecutivos** con los principales hallazgos  

## 📂 Estructura del repositorio
- `docs/data/` → Datasets utilizados en el proyecto  
- `docs/Semana_1/` → Archivos iniciales de análisis y reportes de la primera semana  
- `docs/Semana_2/` → Actualizaciones y profundización del análisis  
- `docs/Semana_3/` → Resultados finales y consolidación del proyecto  

## 🛠 Herramientas utilizadas
- **Excel avanzado** (funciones, tablas dinámicas, gráficos y dashboards)  
- Principios de **Business Intelligence** aplicados al análisis comercial
